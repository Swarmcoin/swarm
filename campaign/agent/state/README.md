# Agent state

`state.json` (what the agent did: posted calendar ids, answered posts, daily counters, the
last 500 actions), `review-queue.json` (proposals waiting for a human) and `last-run.md`
(the latest run report) are written here by `swarm-social` and committed back by the GitHub
Action, so this directory is the public audit log of the account's automation. Nothing here
is secret.
