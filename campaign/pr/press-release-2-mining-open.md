## SWARM opens public mining: anyone can now run a node and mine the privacy coin from a desktop app

*1 November 2026* — At 15:42 UTC today SWARM (SWM) ended its 30-day closed start and opened
mining to everyone. SWARM Node, a desktop application for Windows, Linux and macOS that runs
a full node and mines Equihash 200,9 on the CPU, is published at swarm.green/ecosystem with
its SHA-256 checksum and a mining guide.

**What happened in the closed start.** SWARM mainnet has been live since 2 October 2026. For
29 days only the project's own machines mined; about 33,408 blocks and about 208,800 SWM were
produced, about 0.99% of the maximum supply, each block split like every other: 80% to the
miner, 20% to the three published project funds. For the 24 hours before today's opening,
the [N] people on the public waiting list received the node software in leaderboard order.
Every block is visible in the explorer at mainnet.explore.swarm.green. *(Fill in the
waiting-list count and the final block height at send time.)*

**How mining works.** Install SWARM Node, verify the checksum, enter a SWARM address from
SWARM Wallet, start. The node verifies every block from genesis before it mines. Rewards
mature after 100 blocks. The rules are the same for everyone: there is no admin key, no
checkpoint and no way to mint a coin without finding a block. Equihash 200,9 has specialised
hardware; nothing in the rules keeps larger miners out, and the project says so rather than
promise that home computers stay competitive.

**The coin.** 6.25 SWM per block, a block every 75 seconds, halving every 1,680,000 blocks,
20,999,987.3152 SWM at most. Shielded payments keep the sender, the receiver and the amount
encrypted on the chain. Wallets for desktop and Android, an end-to-end encrypted messenger
with payments inside the chat, and a browser pre-release with the wallet built in are
published at swarm.green/ecosystem.

**Honest statement of the current state.** SWARM is experimental software. No independent
audit of the SWARM-specific changes has been published. Builds are not yet signed. The
project never asks for recovery words, private keys or a payment; the only official channels
are swarm.green, @swarm_coin, swarmofficial@atomicmail.io and github.com/Swarmcoin.

**Quote.** "From this moment the bees that do the work earn the honey. We ran the chain alone
for a month and said exactly why; now the same rules apply to us as to anyone with a
computer." — the SWARM founding team.
